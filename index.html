Resume Analyzer (AI-Powered)

The Resume Analyzer is an AI-powered web application that automatically analyzes resumes uploaded by users. It uses Natural Language Processing (NLP) and Machine Learning to extract key details (skills, education, experience, and achievements) and classify candidates into suitable job domains

  • Automated Resume Parsing: Extracts structured data such as Name, Email, Skills, and Education from raw text or PDF resumes
  • Natural Language Processing (NLP): Uses spaCy for text cleaning, tokenization, POS tagging, and Named Entity Recognition (NER).
  • Candidate Classification: Predicts job domain (e.g., Data Science, Web Development, AI/ML, etc.) using a trained ML model.
  • Text Preprocessing: Regex, Stopword removal, Lemmatization Feature Extraction: TF-IDF / Bag of Words Model Training: Logistic Regression / Naive Bayes / Random Forest Visualization: Matplotlib, WordCloud NER: spaCy pre-trained models

QuickBite

QuickBite is a full-stack, responsive food delivery web application built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. It enables users to browse restaurants, explore menus, place food orders, manage their carts, and track their delivery in real-time. The platform is designed with a user-friendly interface, secure authentication, and efficient backend APIs for smooth end-to-end functionality.

    User Features
  • Restaurant & Menu Browsing: View restaurants, cuisines, prices, and ratings dynamically fetched from MongoDB.
  • Cart Management: Add, update, or remove food items in a persistent shopping cart.
  • Order Placement: Securely place orders and receive confirmation instantly.
  • Real-Time Order Tracking: Track the order status — from “Preparing” → “Out for Delivery” → “Delivered”.

ChatSphere – Real-Time Chat Application

ChatSphere is a full-stack MERN (MongoDB, Express.js, React.js, Node.js) based real-time chat application built with Socket.io for instant communication. It provides a seamless chatting experience through private and group conversations, live online status, and message delivery/read indicators, similar to modern chat platforms like WhatsApp or Discord.

  • Real-Time Messaging: Instant one-to-one and group chat functionality powered by Socket.io.
  • Private & Group Chats: Create or join chat rooms and interact with multiple users at once.
  • Online/Offline Status: See who’s currently online and active.
  • Message Indicators: Visual confirmation for sent, delivered, and seen messages.
  • User Authentication: Secure login and signup using JWT tokens. Chat History: All messages are stored and retrievable from MongoDB. Responsive UI: Optimized for smooth chat experience across devices.
